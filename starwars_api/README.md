# Star Wars API

## Description

This project is part of the Holberton School Interview Preparation curriculum.

The goal is to create a JavaScript script that retrieves and displays the names of all characters from a specified Star Wars movie using the Star Wars API.

The characters must be displayed in the same order as they appear in the API response.

## Requirements

- Node.js
- JavaScript
- `request` module
- Semistandard coding style
- Executable JavaScript file

## Files

| File | Description |
|---|---|
| `0-starwars_characters.js` | Fetches and prints Star Wars character names in order. |
| `README.md` | Project documentation. |

## Usage

```bash
./0-starwars_characters.js 3
```

Example output:

```text
Luke Skywalker
C-3PO
R2-D2
Darth Vader
Leia Organa
...
```

## Concepts Learned

- Working with REST APIs
- Making HTTP requests using Node.js
- Parsing JSON responses
- Handling asynchronous callbacks
- Reading command-line arguments
- Preserving the order of asynchronous operations
