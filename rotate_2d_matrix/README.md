
# Rotate 2D Matrix

This project implements a Python function that rotates an
n x n matrix 90 degrees clockwise in-place.

## Function

`rotate_2d_matrix(matrix)`

The function modifies the original matrix without returning
a new matrix.

## Approach

1. Transpose the matrix.
2. Reverse each row.

## Requirements

- Python 3
- No module imports
- PEP 8 style
